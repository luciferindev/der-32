UPKG(8) System Manager's Manual UPKG(8)

NAME

upkg —
DER/32 Unix package manager

SYNOPSIS

upkg [-v] [-r root] command [arguments]

DESCRIPTION

upkg installs, removes and upgrades third-party software on DER/32. Packages come from any number of configured repositories, each published with an Ed25519-signed index; every package archive is verified against the SHA-256 digest recorded in that signed index before anything is installed. Packages install below /usr/local by default; the base system is never modified by upkg.

The global options are:

-r root
Operate on the system rooted at root instead of /. Configuration, the database and the installed files are all taken relative to root.
-v
Print debugging output.

COMMANDS

sync
Download every enabled repository's INDEX and INDEX.sig, verify the signature against the trusted keys in /etc/upkg/keys, and refuse indexes that name a different repository or are older than the copy already held.
install [-n] [--asdeps] [--nodeps] [--allow-unsigned] package ...
Install packages and their dependencies. A package is name, repo/name (take it from that repository only), name[<,<=,=,>=,>version] or the path of a local .upkg file (which requires --allow-unsigned). -n only prints the transaction.
remove [-n] [-c] package ...
Remove packages. Removal of a package another package depends on is refused unless -c is given, in which case the dependents are removed as well.
autoremove [-n]
Remove packages that were installed only as dependencies and are no longer required.
upgrade [-n]
Upgrade every installed package for which a repository offers a newer version.
search query
Search package names and descriptions.
info package
Show installed and repository information.
list [-e | -d] [-f package]
List installed packages (-e: explicitly installed only, -d: dependencies only), or the files owned by package.
check [package ...]
Verify installed files against the checksums in the database.
build [-o output] port
Build a package from the source recipe port (a directory, or a name looked up in portsdir). When run as root the build runs as the unprivileged build_user. Recipes are only ever executed on explicit request.
repo list | add name url [-p prio] [-k key] [--disabled] | remove name | enable name | disable name | priority name n
Manage repositories.
keygen prefix
Create prefix.key and prefix.pub.
create -i PKGINFO -d stagedir [-o file]
Create a package from a staging directory.
index -n repo -k keyfile dir
Write and sign dir/INDEX.
recover
Complete or undo an interrupted transaction. This also happens automatically before any command that modifies the system.
vercmp a b
Print -1, 0 or 1.

FILES

/etc/upkg/upkg.conf
options: arch, prefixes, portsdir, builddir, build_user, ca_file, allow_http
/etc/upkg/repos.conf
repositories: url, priority, enabled, key
/etc/upkg/keys/
trusted Ed25519 public keys
/var/lib/upkg/upkg.db
installed package database
/var/lib/upkg/journal
transaction journal
/var/cache/upkg/
downloaded packages and distfiles

EXIT STATUS

The upkg utility exits 0 on success, and >0 if an error occurs.

EXAMPLES

# upkg repo add core https://example.org/der32/core -p 100
# upkg sync
# upkg install core/curl
# upkg remove curl && upkg autoremove

SEE ALSO

pkg_add(1), hier(7)
