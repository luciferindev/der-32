! DER/32 cheat sheet
Sticky · Forum: HOWTOs

The commands you'll want in the first hour. Print it out and tape it to your monitor. Jump to: upkg · pkgin · system · services · network · users · building

P upkg: DER/32 packages
CommandWhat it does
upkg syncfetch and verify every enabled repository index (online + medium)
upkg search luasearch package names and descriptions
upkg info luainstalled and repository information
upkg install tree nnninstall with dependencies (-n: dry run)
upkg install core/luatake the package from one repository only
upkg install 'lua>=5.4'version constraint: < <= = >= >
upkg upgradeupgrade everything that has a newer version
upkg remove lua-helloremove (refused if something depends on it)
upkg remove -c luaremove together with its dependents
upkg autoremovedrop dependencies nothing needs any more
upkg list -eexplicitly installed packages (-d: dependencies)
upkg list -f luafiles owned by a package
upkg checkverify installed files against their checksums
upkg build der32-hellobuild a package from a recipe in ports/
upkg repo listrepositories, priorities, enabled state
upkg repo add web URL -p 90add a repository with priority 90
upkg recoverfinish or undo an interrupted transaction

Full reference: upkg(8).

P pkgin: NetBSD binary packages
CommandWhat it does
pkg_add pkginone-time bootstrap from cdn.NetBSD.org
pkgin updaterefresh the package list
pkgin search vimsearch
pkgin install vim gitinstall with dependencies, into /usr/pkg
pkgin upgradeupgrade installed packages
pkgin remove vimremove
pkgin autoremoveremove orphaned dependencies
pkgin listinstalled packages
pkg_infoinstalled packages, the low-level way
S System
CommandWhat it does
derfetchsystem info and the tortoise (-l no logo, -n no colour)
der32-installinstall DER/32 to a disk (from the USB stick or ISO)
startxstart X (XFCE, if you installed it)
uname -akernel name, release, version
sysctl kern.der32DER/32 release name and codename
cat /etc/releaserelease and build information
dmesg | lesskernel boot messages: what hardware was found
topprocesses
df -hdisk space
sysctl hw.physmem64installed memory, in bytes
shutdown -p nowpower off
shutdown -r nowreboot
certctl rehashrebuild /etc/openssl/certs (HTTPS trust)
S Services (rc.d)
CommandWhat it does
vi /etc/rc.confturn services on and off: cron=YES
service cron restartcontrol a service now (also start, stop, status)
service -llist every rc.d script
service ntpd onestartstart once without enabling it in rc.conf
ls /etc/rc.dthe service scripts themselves
N Network
CommandWhat it does
ifconfig -ainterfaces and addresses
service dhcpcd restartredo DHCP on every interface
route -n showrouting table
cat /etc/resolv.confDNS servers (written by dhcpcd)
ping -c 3 netbsd.orgcheck connectivity
ftp https://example.org/filedownload a file (base has no curl or wget)
U Users
CommandWhat it does
passwdchange your password (do this first as root)
useradd -m -G wheel aliceadd a user with a home directory, allowed to su
passwd aliceset their password
su -become root (users in group wheel only)
userdel -r aliceremove a user and their home
B Building DER/32 (on the Linux host)
TargetWhat it does
make checkcheck the host for required tools
make releasetools, kernel, world, sets, repos, all images
make installerUSB installer image
make isolive + install ISO
make image-pcdisk image with a screen console
make qemuboot the image here, serial console (exit: Ctrl-A X)
SNAPSHOT=1 make qemuboot without keeping any disk changes
make testevery test suite
python3 scripts/install-test.py out/images/*.isoinstall to a blank disk, boot it (BIOS and UEFI)
make test-upkgonly the upkg suite (fast, no NetBSD build needed)
make kerneljust the DER32 kernel
scripts/patches.sh statuspinned NetBSD commit and patch state
make cleanremove build output
