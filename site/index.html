! Welcome to DER/32

DER/32 (“Derivative 32”) is a small, bootable UNIX for amd64, derived from NetBSD 10. It's BSD all the way down: BSD make, BSD init and rc.d, POSIX sh, FFS. On top of that it has its own package manager, upkg, written in C.

There's no systemd, no GUI installer and no telemetry. You get a serial console, a login prompt and a tortoise.

N In testing: NetBSD binary packages on DER/32
Posted by luciferindev on Thursday, November 19, 2026 · Topic: Packages

DER/32 keeps the NetBSD 10 ABI, so NetBSD's own pkgsrc binary packages install unmodified under /usr/pkg, alongside upkg's /usr/local. The next build ships an /etc/pkg_install.conf that points pkg_add at cdn.NetBSD.org. It's being tested now:

der32# pkg_add pkgin der32# pkgin update der32# pkgin install vim git
FAQ: But uname -s says DER32?pkg_add checks the package's OS against a compile-time constant, not against uname. Your packages won't notice.

N DER/32 0.1 “Genesis” boots
Posted by luciferindev on Thursday, November 19, 2026 · Topic: Releases

The first development release builds from a clean clone on Arch Linux and boots to a login prompt, both as a disk image and as a live ISO. The automated test suites check the upkg package manager, the build and the booted system.

The kernel reports DER32 and carries its release in kern.der32.* sysctls. NetBSD's kern.osrelease is kept, so kernel modules and binaries stay compatible.

? HOWTO: Build and boot DER/32
Sticky · Topic: Installation

You need a Linux host (Arch is the reference), a C compiler, about 20 GB of disk, and QEMU. No root required.

$ git clone --recurse-submodules https://github.com/luciferindev/der-32 $ cd der-32 $ make release # tools, kernel, world, sets, disk image $ make iso # live ISO $ make qemu # boot it on a serial console $ make test # run the test suites

Images land in out/images/. Log in as root, password der32, and change it. Prebuilt images will go on the releases page.

? HOWTO: upkg in one minute
Sticky · Topic: Packages
der32# upkg sync # verify signed indexes der32# upkg install lua-hello # pulls lua as a dependency der32# upkg install community/der32-hello der32# upkg remove lua # refused: lua-hello needs it

upkg handles multiple repositories with priorities, Ed25519-signed indexes, SHA-256 checksums, version constraints and journaled transactions that survive a power cut. It never runs install scripts.
