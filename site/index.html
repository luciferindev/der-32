DER/32 — Derivative 32

A small, bootable UNIX for amd64, derived from NetBSD 10. BSD make, BSD init, POSIX sh, FFS, and a package manager of its own. Release 0.1 “Genesis”.

DER/32 UNIX Operating System
Release 0.1 — Genesis

What it is

base
NetBSD netbsd-10 (10.2), kept as a pinned upstream plus a short, reviewable patch series. Same ABI, same drivers.
identity
Real, not cosmetic: the kernel reports DER32, and kern.der32.* sysctls carry the release.
upkg
A package manager in C. Multiple repositories with priorities, Ed25519-signed indexes, SHA-256 checksums, dependency resolution, journaled transactions that survive interruption, and no install scripts. Everything goes under /usr/local.
pkgsrc
NetBSD's binary packages install unmodified under /usr/pkg, through pkg_add and pkgin.
derfetch
System info in the base system, with the tortoise.
build
Cross-built from Linux (Arch is the reference host) with NetBSD's build.sh. No root needed.

Build & boot

You need about 20 GB of disk, a C compiler, and QEMU to try it.

$ git clone --recurse-submodules https://github.com/luciferindev/der-32
$ cd der-32
$ make release      # tools, kernel, world, sets, disk image
$ make iso          # live ISO
$ make qemu         # boot it on a serial console
$ make test         # upkg suite, build checks, booted-system checks

Images land in out/images/. The default login is root / der32, and docs/building.md has the details. Prebuilt images, when published, are on the releases page.

Status

Genesis is a development release. The disk image and the live ISO boot to a login prompt and pass the automated checks. Known gaps (a VGA console image, an installer, a first-boot password prompt) are tracked in docs/roadmap.md.
