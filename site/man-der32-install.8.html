DER32-INSTALL(8) System Manager's Manual DER32-INSTALL(8)

NAME

der32-install —
install DER/32 onto a disk

SYNOPSIS

der32-install [-f answer-file] [-s sets-dir]

DESCRIPTION

der32-install installs DER/32 from a booted install medium, the live ISO or the USB installer image, onto a disk. It asks a few questions, then:
  1. replaces the disk's partition table with a GPT holding a 256 MiB EFI system partition (der32efi), optional swap (der32swap) and an FFSv2 root using the rest of the disk (der32root);
  2. extracts the release sets (base, etc, comp, man, misc, text, kern-DER32);
  3. installs both the BIOS boot loader (GPT boot code plus /usr/mdec/bootxx_ffsv2) and the UEFI loader EFI/BOOT/BOOTX64.EFI, so the disk boots either way;
  4. writes /etc/fstab (by GPT label), /etc/rc.conf, /boot.cfg and the time zone, sets root's password and optionally creates a user in group wheel;
  5. optionally installs the X11 sets and the XFCE desktop from NetBSD's binary packages with pkgin(1). This needs a working network connection.

Nothing is written to any disk until the disk is confirmed by typing “erase disk”. The disk the installer itself booted from is never offered.

The options are:

-f answer-file
Run without questions. The file is read by sh(1) and sets the variables below.
-s sets-dir
Take the sets from sets-dir instead of /der32/sets.

ANSWER FILE

DISK
target disk, for example wd0
CONFIRM
must be “erase $DISK”
HOSTNAME
default der32
TIMEZONE
a name under /usr/share/zoneinfo, default UTC
CONSOLE
screen or serial
SWAP_MB
swap size, 0 for none
ROOT_PWHASH
root's password hash, from pwhash(1) (required)
USERNAME
optional user to create
USER_PWHASH
that user's password hash
DHCP, XFCE
yes or no

FILES

/der32/sets
release sets on the install medium
/tmp/der32-install.log
log of the run, copied to /var/log/der32-install.log on the new system

EXAMPLES

# der32-install

Unattended:

DISK=wd0
CONFIRM="erase wd0"
HOSTNAME=tortoise
TIMEZONE=America/Boise
CONSOLE=screen
SWAP_MB=1024
ROOT_PWHASH='$argon2id$v=19$...'
DHCP=yes XFCE=no

SEE ALSO

pkgin(1), pwhash(1), upkg(8), boot(8), gpt(8), installboot(8)

HISTORY

der32-install first appeared in DER/32 0.1 “Genesis”.

BUGS

The SSH server is not offered: in DER/32 0.1, loading SSH private keys hangs, so an enabled sshd(8) would stop the boot.

CAVEATS

The XFCE option downloads several hundred megabytes from cdn.NetBSD.org. If that fails, the X11 sets are still installed and the desktop can be added later with pkgin install xfce4.
