DERFETCH(1) General Commands Manual DERFETCH(1)

NAME

derfetch —
show system information next to Genesis the tortoise

SYNOPSIS

derfetch [-lnV]

DESCRIPTION

derfetch prints the DER/32 mascot, Genesis the tortoise, beside a summary of the running system: the DER/32 release from the kern.der32 sysctl tree, the NetBSD base release, the kernel configuration and build, uptime, the number of packages installed by upkg(8), shell, terminal, CPU, memory and root filesystem usage.

The options are:

-l
Do not print the logo.
-n
Do not use color. Color is also off when standard output is not a terminal or NO_COLOR is set.
-V
Print the version and exit.

ENVIRONMENT

NO_COLOR
Disable color.
UPKG_ROOT
Count packages in the upkg database and the pkgsrc database (/usr/pkg/pkgdb) below this root.

FILES

/var/lib/upkg/upkg.db
installed package database, read-only

SEE ALSO

uname(1), sysctl(7), upkg(8)
